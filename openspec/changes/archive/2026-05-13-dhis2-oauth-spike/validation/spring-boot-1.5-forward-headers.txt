--- Relevant excerpt ---

If you run your Spring Boot application behind a reverse proxy server (e.g.
nginx or Apache) there may be some useful additional configuration which you
can apply. For example, many reverse proxies will pass header information that
can be used to determine the original server name, port and scheme (HTTP or
HTTPS), etc.

To configure Tomcat to use the X-Forwarded-* headers sent by a front-end
proxy, add the following to your application.properties (or application.yml):

  server.use-forward-headers=true

When set to true, Spring Boot configures Tomcat's RemoteIpValve, which makes
request.getScheme() and request.isSecure() reflect the X-Forwarded-Proto
header value sent by the proxy. This means request.isSecure() returns true
when behind an HTTPS-terminating proxy, even if the backend connection is HTTP.

The following additional properties can be used to customise the valve:
  server.tomcat.remote-ip-header      (default: x-forwarded-for)
  server.tomcat.protocol-header       (default: x-forwarded-proto)
  server.tomcat.internal-proxies      (regex; default: common private ranges)
